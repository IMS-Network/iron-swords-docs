# ברוכים הבאים


ברוכים הבאים לספר המדריכים של פורטל הגיבורים. 

פלטפורמת הגיבורים מוקדשת מוקדש לחללי צה״ל שמסרנו את נפשם בהגנה על מדינת ישראל ועל הזכות שלנו לחיות כאן

הסיבה שאתם קוראים את הטקסט הזה היא הודות לאותם גיבורים, שהקדישו את החיים שלהם עד לנשימה האחרונה

## להגן על הזכות שלנו לחיות פה 🇮🇱🎗️


בפורטל גיבורים אנחנו מפרסמים את הסיפור של אותם גיבורים

יחד, נוכל ליצור זיכרון תמידי ברשת לכל אחד מחללי המלחמה ולספר לכולם את הסיפור שלהם
