# ברוכים הבאים  

ברוכים הבאים לספר המדריכים של **פורטל הגיבורים**.  

פורטל הגיבורים מוקדש לזכר חללי צה״ל, שהקריבו את חייהם למען הגנה על מדינת ישראל ועל הזכות שלנו לחיות כאן בביטחון ובחופש.  

הטקסט שאתם קוראים כעת נכתב מתוך הכרת תודה עמוקה לגיבורים הללו – אנשים שוויתרו על כל חלום אישי כדי להבטיח את עתידנו כאן.  

## להנציח, לזכור, ולהוקיר 🇮🇱🎗️  

בפורטל הגיבורים אנו מחויבים לספר את סיפורם של הנופלים – גיבורים שהותירו אחריהם מורשת של אומץ, אהבה ומסירות שאין לה שיעור.  

יחד, נוכל להקים זיכרון דיגיטלי נצחי לכל אחד מחללי המלחמות ולוודא שהסיפורים שלהם ימשיכו להדהד לדורות הבאים.
