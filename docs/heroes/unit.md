# יחידה

את רשימת היחידות והגיבורים המצוותים להם אפשר למצוא בממשק ניהול היחידות 
בממשק יש רשימת היחידות והמזהה היחודי של כל יחידה במערכת
בנוסף אפשר לראות את השם, מזהה הכתובת שלה כמות חללים שנפלו במהלך המלחמה ומקשורים לאותה יחידה

בממשק ניתן להוסיף יחידה חדשה, לערוך יחידה קיימת ולמחוק יחידה קיימת

## הוספת יחידה
הוסף יחידה חדשה
שם
השם שיוצג באתר.

מזהה כתובת
המזהה שיוצג בשורת הכתובת. יכול להכיל רק אותיות, מספרים ומקפים.

יחידת אב

ללא
הקצה מונח אב כדי ליצור היררכיה. המונח יונקים, למשל, יהיה מונח האב של נמר ולוויתן.

תיאור
התיאור אינו מוצג כברירת מחדל, אבל תבניות מסוימות עשויות להציג אותו.
